# Whiteboat water distribution source

This public repository contains the desktop Obsidian water-entry distribution. Product scope: WB-ENTRY-006 and WB-ENTRY-008, with native Canvas creation. Preserve these boundaries and run the documented core/plugin test and build checks before changes.

The vendored core is a revision-bound distribution snapshot, not a second shared engineering source. Its origin and file hashes are in source-provenance.json. Maintainers update it from the canonical private Whiteboat core and regenerate provenance; do not silently diverge shared feature bodies.

For work inside the maintainer workspace, first read the adjacent whiteboat/AGENTS.md and its Pensieve. External contributors can use this repository documentation; the private control Vault is not needed to build.
